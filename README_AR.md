# AnimeSport — مشروع أندرويد أولي

هذا مشروع Android Studio أولي باسم AnimeSport، بواجهة عربية وتصميم أسود/أحمر/أزرق، ويضم أقسامًا تجريبية لأخبار كرة القدم والجوائز واللاعبين والأندية والأهداف والأحداث، مع بحث ومفضلة وسعرًا مقترحًا لإزالة الإعلانات: 150 دج شهريًا.

## فتح المشروع
1. فك ضغط الملف.
2. افتح Android Studio.
3. اختر **Open** وحدد مجلد `AnimeSportAndroid`.
4. انتظر مزامنة Gradle، ثم شغّل التطبيق على هاتف متصل أو محاكي.

## ما يعمل الآن
- واجهة عربية محلية داخل التطبيق.
- التنقل بين أخبار كرة القدم، الأهداف والأحداث، الجوائز، اللاعبين والأندية، والبحث وإضافة العناصر للمفضلة ضمن الجلسة.
- روابط إلى مصادر رسمية للأخبار، منها UEFA وFIFA وموقع الكرة الذهبية والاتحاد الجزائري لكرة القدم.
- عرض مساحة إعلانات تجريبية للمستخدم المجاني.
- مشغّل فيديو يقبل رابط HTTPS يوفّره مزوّد مرخّص؛ دعم HLS يعتمد على الجهاز والمزوّد.
- إظهار سعر الاشتراك 150 دج شهريًا كنموذج واجهة.

## ما لا يعمل بعد
- لا يوجد بث مباشر فعلي ولا كتالوج حلقات مرخّص؛ يلزم الحصول على الروابط وحقوق العرض من مزوّد مرخّص.
- لم نعد نعرض نتائج مباريات تجريبية. قسم الأهداف والأحداث يوضح أن بيانات البث المباشر غير متصلة بعد.
- لا توجد إعلانات مدفوعة فعلية.
- لا توجد عملية دفع أو تحقق حقيقي من الاشتراك؛ زر الاشتراك يشرح الخطوة المطلوبة فقط.
- هذا المشروع مصدر قابل للبناء وليس APK جاهزًا للتثبيت. يلزم Android Studio/Android SDK لبنائه، ثم توقيعه قبل التوزيع.

## قبل النشر
- ربط مصادر بث تملك إذنًا قانونيًا لتوزيعها.
- ربط API موثوق للأخبار والنتائج والأهداف بالدقيقة والبطاقات والتبديلات والإحصائيات واللاعبين والأندية؛ بعض الخدمات تتطلب مفتاح API أو اشتراكًا.
- ربط شبكة إعلانات مناسبة مع الالتزام بسياساتها.
- إضافة نظام دفع آمن والتحقق من الاشتراك على الخادم، ثم إزالة الإعلانات بعد تأكيد الدفع.
- إضافة سياسة خصوصية وشروط استخدام.
